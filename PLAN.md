# План разработки Relay Chat

## Объём задания

Один общий сервер и три клиента: браузер, Android/iOS (Ionic React + Capacitor), Windows/Linux/macOS (Electron). Список каналов, история сообщений, отправка в реальном времени. Проект готовится индивидуально.

## Этапы

1. Архитектура и инфраструктура: monorepo, Node.js 22+, PostgreSQL, Docker Compose; локальный запуск без Docker через PGlite.
2. Сервер: регистрация и вход, сессии, публичные/приватные каналы, участники, права, сообщения, история с курсором, ответы, редактирование и удаление своих сообщений.
3. Realtime: Socket.IO, подписки на каналы, печатает, переподключение, идемпотентная отправка; Redis adapter для нескольких серверов.
4. React-интерфейс: адаптивный список каналов и переписка, поиск, непрочитанные, профиль, выбор сервера.
5. Клиенты: нативные проекты Capacitor и оболочка Electron; воспроизводимые сборки в GitHub Actions.
6. VM: Nginx, API, PostgreSQL, Redis; Elasticsearch подключается профилем search; тома и резервное копирование.
7. Проверки: тесты API/прав, два браузерных клиента, мобильный размер, нагрузочный генератор с метриками доставки.
8. Сдача: README, схема, руководство по демонстрации, Git с main/develop и тематическими ветками, архив и Git bundle.

## Критерии готовности

- Два пользователя видят сообщения друг друга без обновления страницы.
- История и аккаунты сохраняются после перезапуска сервера.
- Нельзя читать чужой приватный канал или менять чужое сообщение.
- Повтор отправки с тем же clientId не создаёт дубль.
- Интерфейс работает на телефоне и компьютере.
- Docker Compose содержит всё для доступа по IP виртуальной машины.
- Нагрузочный тест проверяет и HTTP-успех, и доставку через WebSocket.
- README различает проверенные здесь сценарии и сборки, требующие Android SDK/macOS/Windows.
